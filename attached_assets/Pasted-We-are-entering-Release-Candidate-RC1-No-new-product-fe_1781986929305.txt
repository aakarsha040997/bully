We are entering Release Candidate (RC1).

No new product features.

No UI redesign.

No new screens.

The goal is to make Bully production-grade.

---

# 1. Complete Project Audit

Review the entire codebase.

Find:

* dead code
* duplicate code
* unused components
* unused assets
* unused dependencies
* unnecessary renders
* unnecessary AsyncStorage writes
* memory leaks
* race conditions
* stale state
* unnecessary re-renders
* expensive computations

Optimize everything.

---

# 2. Battery Optimization

Review every background task.

Minimize:

* CPU wakeups
* unnecessary UsageStats reads
* duplicate monitoring cycles
* duplicate notifications

Ensure monitoring only runs when necessary.

Measure approximate battery impact.

---

# 3. Error Handling

Review every async operation.

Ensure every failure has:

* graceful fallback
* logging
* no crashes
* user-friendly behavior

Especially:

UsageStats

Notifications

AsyncStorage

Groq API

WorkManager

---

# 4. Offline Mode

Audit the app.

Ensure:

Everything except AI Verdict works without internet.

If Groq fails:

Show a local fallback verdict.

Never leave the user with a blank state.

---
